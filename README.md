# WAYGO

Статический сайт на GitHub Pages. Сборка для публикации не требуется.

## Адреса, страны и валюты

Введите город или адрес и нажмите **Найти** (или Enter), затем выберите результат с нужной страной. Одноимённые города не выбираются автоматически. Фильтр в шапке ограничивает поиск; по умолчанию поиск идёт по всему миру. Страна и валюта определяются по ISO-коду результата Photon, а не по фрагментам введённого названия.

Справочник охватывает 255 регионов Unicode CLDR 49, действующие валюты выбраны на 16.11.2026. Для регионов с несколькими валютами отображаются все перечисленные в CLDR действующие платёжные валюты. Данные: [Unicode CLDR](https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-core/supplemental/currencyData.json), лицензия в `assets/UNICODE-LICENSE.txt`. Справочник нужно обновлять при изменении валют.

## Маршрут и цена

OSRM возвращает геометрию автомобильного маршрута, расстояние и длительность. На карте рисуется эта геометрия. Пробки не учитываются. Если сервис недоступен, точки совпадают или адрес не подтверждён, цена не подменяется примером. Изменение адреса удаляет предыдущий расчёт; запоздавшие ответы не восстанавливают его.

Для международных маршрутов цена согласуется отдельно; валюта показывается по месту отправления.

Сохранены исходные **демонстрационные** ставки для 20 рынков. Это не проверенные цены перевозчиков. У других стран определяется валюта и строится маршрут, а цена предлагается к согласованию.

Настройки в `assets/config.js`. Ставки задаются в местной валюте:

```js
rates: {
  ru: {base: 250, km: 32},
  de: {base: 5, km: 2.2}
}
```

Формула: `(посадка + км × ставка) × коэффициент тарифа`. Коэффициенты: Эконом 1, Комфорт 1.55, Бизнес 2.6. Округление по дробным разрядам валюты. После утверждения **всех** ставок можно изменить `ratesAreDemo`; при этом также нужно обновить статические предупреждения о демо-ценах в HTML.

## Заявки

Форма поездки / подключения готовит письмо на **verrssan@gmail.com**, включая выбранный маршрут, страну, валюту и предварительную стоимость. Посетитель отправляет письмо сам в почтовом приложении. Альтернатива — скачать TXT и отправить его вручную. Сайт не сообщает об успешной доставке, не назначает машину и не хранит контакты в браузерном хранилище.

Автоматическая отправка прямо с сайта потребует серверного обработчика и почтового провайдера или API сервиса заказов. Ключи API нельзя помещать в публичные файлы сайта. Тестовые письма при проверке не отправлялись.

## Внешние сервисы и ограничения

- [Photon](https://github.com/komoot/photon): явный поиск по кнопке, кэш в памяти страницы, отмена устаревших запросов. Публичный сервер допускает умеренную нагрузку и не гарантирует доступность; для рабочего сервиса нужен собственный экземпляр или провайдер с подходящими условиями. Адрес меняется в `geocoderUrl`.
- [OSRM](https://project-osrm.org/docs/v5.24.0/api/): публичный сервер для демонстрации. Для эксплуатации нужен собственный сервер или сервис маршрутизации; URL в `routerUrl`.
- [OpenStreetMap tiles](https://operations.osmfoundation.org/policies/tiles/): атрибуция сохранена. Адреса передаются геокодеру по кнопке, координаты — маршрутизатору при расчёте. Карта запрашивает тайлы отображаемой области.

## Проверка

Node.js 22+:

```sh
npm ci
npm test
```

Тесты проверяют валюты, формулы, геометрию, ошибки сети, отмену старых расчётов и скачивание заявки без отправки контактов. Ручная проверка реальных Photon/OSRM: Москва, Берлин — Потсдам (EUR), Виннипег — Брэндон (CAD), мобильная ширина 390 px.

Локальный просмотр:

```sh
python -m http.server 8917 --bind 127.0.0.1
```

Публикация: GitHub Pages, ветка `main`, корень репозитория.
